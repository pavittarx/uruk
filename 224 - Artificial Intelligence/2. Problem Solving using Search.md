Problem Solving using Search

## Overview

Before an AI problem can be solved, it must be represented as a **state space**, which is the set of all possible states reachable from the initial state. This space is commonly defined as a directed graph or tree. In this representation:

- **Nodes** represent each state of the problem.
- **Arcs (or links) between nodes** represent the legal moves or actions that can be taken to change from one state to another.
- The **initial state** is the starting point.
- The **goal state** is the desired state.

A **solution** is a path from the initial state to a goal state. This path comprises a sequence of actions (operators) that transform one state into another. The **cost of a path** is a positive number, typically the sum of the costs of each action. An **optimal solution** has the lowest path cost.

**Search** is the process of finding a solution path by moving through the state space. Search algorithms are evaluated based on:

- **Completeness:** Whether they guarantee finding a solution if one exists.
- **Optimality/Admissibility:** Whether they guarantee finding the best solution (lowest path cost).
- **Time complexity:** How long it takes to find a solution.
- **Space complexity:** How much memory the algorithm uses.

**Uninformed search** methods do not use any domain knowledge about the goal state. Some common uninformed search algorithms include:

- **Breadth-first search (BFS):** Expands the search tree level by level, exploring all nodes at a given depth before moving to the next level.
- **Depth-first search (DFS):** Expands the search tree by exploring as far as possible along each branch before backtracking.
- **Iterative deepening depth-first search (IDDFS):** Performs a series of depth-limited DFS searches with increasing depth limits until a solution is found.
- **Bidirectional search:** Searches forward from the initial state and backward from the goal state simultaneously, hoping to meet in the middle.

**Informed search**, also known as **heuristic search**, uses domain-specific knowledge to guide the search towards the goal state.  This knowledge is often encoded in a **heuristic function**, which estimates the cost of the cheapest path from a given node to a goal node.

Informed search algorithms include:

- **Best-first search:** Orders the nodes to be expanded based on an evaluation function that indicates how promising a node is.
- **Greedy best-first search:** Always expands the node that appears closest to the goal, based on the heuristic function.
- *A\ search:* Combines the cost to reach a node from the start state (g(n)) with the estimated cost to reach the goal from that node (h(n)) using the formula f(n) = g(n) + h(n). It prioritizes nodes with the lowest f(n).

Problem-solving using search is a fundamental concept in AI, enabling agents to find solutions to a wide range of problems by systematically exploring the possible states and actions. The choice of search algorithm depends on the specific problem and the desired balance between completeness, optimality, time complexity, and space complexity.

## Problems in AI

There is hardly ever a straightforward solution to AI problems. There is no guaranteed direct procedure (like solving a quadratic equation). For example, consider the task of scheduling flights for a major airline with hubs across the country. The number of possible flight schedules is astronomical, even for a relatively small number of flights and aircraft. Trying to evaluate every possible combination to find the optimal schedule is computationally intractable.

In order to solve such problems, AI utilizes the power of search. It can be said that, **All AI problems are search problems.** The challenges in AI are structured in a way that allows for application of search algorithms.

**Key Components of an AI Problem**

1. Initial State - the starting state of the problem.
2. Goal (or Final State) - this is the end or the desired state. 
3. Operators - rules governing the transition between states. 
4. State Space - universe of all possible states. 

AI requires a problem to be presented in a structured way before proceeding to find a solution. State Space is used to represent AI problems. It is a map of all possible configurations (or arrangements) of elements related to a problem. The state space is not just a collection of states; it also encompasses permissible actions (operators) that allow transition between states.

**Problem Space**

A problem space is a set of all possible state, actions and transitions that might arise when trying to solve a problem. It represent the complete range of paths from initial state to the desired goal state. 

A problem space is represented by a direct graph, where nodes represent search state and path represent operators applied to change the state. To simplify (reduce the complexity of) search algorithms, it is often convenient to logically and programmatically represent the problem space as a tree. This comes at the cost of duplicated tree nodes, due to multiple link to the nodes within the graph.

**Search Problem Definition**: 
In AI, a search problem is defined by its components, which include an initial state, a set of possible actions (operators), a transition model that describes how actions change states, a goal state, and a cost function for the actions. The objective is to find a sequence of actions that leads from the initial state to the goal state.

**State Space**: 

The problem space consists of all possible states that can be reached from the initial state through various actions. Each state represents a potential configuration of the problem, and the connections (or paths) between these states represent the actions taken to transition from one state to another.

**Search Algorithms**: 

AI employs search algorithms to navigate through the problem space. These algorithms systematically explore the state space to find a solution that meets the defined goal. They can be classified into two main categories:

- **Uninformed Search**: These algorithms have no additional information about the states beyond the problem definition and explore the search space blindly.
- **Informed Search**: These algorithms use heuristics or additional knowledge about the problem domain to guide the search process more efficiently.

**General Applicability**: The formulation of problems as search problems allows for a standardized approach to a wide range of tasks, from simple puzzles to complex decision-making scenarios. This framework enables AI systems to apply established search techniques to diverse problems, making it a foundational concept in the field

### Solving AI problems (State Space Search)

An AI problem must be represented as a state space before it can be solved. Initial State and Final (Goal) states are two special states among all possible states. 

A successor function (set of operators) is used to change the state. It is used to transition from a state to another. 

A state space essentially consists of a set of nodes representing each state of the problem, arcs between nodes represent legal moves from one state to another. Each state space takes the form of a tree or a graph. 

The process of searching means a sequence of actions that you take from initial state to goal state.

In order to solve AI problems, 

1. Define the problem precisely — find initial & final configuration for an acceptable solution to the problem. 
2. Analyze the problem — find few important features that would identify the appropriate techniques for solving the problem. 
3. Isolate & represent task knowledge necessary to solve the problem. 
4. Choose the best techniques and apply it to particular problem. 

Formal Description of the process —-

1. Define a state space that contains all possible configurations of the relevant objects. 
2. Identify one or more states within the space, (initial states) from which problem solving process can start. 
3. Specify one or more goal states. 
4. Define the set of rules for actions (operators) that can be taken.
